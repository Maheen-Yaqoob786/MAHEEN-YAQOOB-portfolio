# Maheen Yaqoob — Academic & Professional Portfolio

A modern, responsive React and TypeScript portfolio application for **Maheen Yaqoob** — Psychology graduate, Behaviour Therapist, researcher, and international Master's student at Universitas Islam Internasional Indonesia (UIII).

## Highlights & Features

- **Hero & Identity**: Elegant typography and warm aesthetic palette, interactive portrait monogram frame with photo preview capabilities, and live academic impact statistics.
- **About Me**: Core philosophy ("People. Purpose. Progress.") and narrative highlighting empirical research, behavioural therapy, and cross-cultural perspective.
- **Education & Research Journey**: Details on international Master's study at UIII, BS in Applied Psychology (CGPA 3.26/4.00), and undergraduate thesis with direct view options and summary modal.
- **Professional Practice Timeline**: Experience at Children Health Care Center (SAC), Social Security Hospital, Young Psychologist Society, and Mian Afzal Trust Hospital Drug Rehabilitation Center.
- **Research & Publications**: Published peer-reviewed journal papers (with one-click APA citation copy) and ongoing research studies in stress, self-efficacy, and adolescent metacognition.
- **Community Projects**: Social work, climate change awareness initiatives, disaster relief volunteering (Rescue 1122), and merit award programmes.
- **Skills & Certifications**: Interactive competency badges, specialized psychology certifications, seminar history, and personal passions.
- **Contact & Collaboration**: Direct mail, location info, interactive message draft composer, and clipboard utilities.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS with custom academic palette (`cream`, `beige`, `sand`, `brown`, `deep`)
- **Icons**: Lucide React
- **SEO & Social**: OpenGraph, Twitter Cards, and Schema.org `Person` JSON-LD

## Development

```bash
# Install dependencies
npm install

# Run dev server on port 3000
npm run dev

# Build for production
npm run build
```
